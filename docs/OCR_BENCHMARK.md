# JurisScan-AI OCR Benchmark

This report records a measured run of the Phase 1-3 OCR pipeline. Every CER, WER, confidence, timing and memory value below is from the run recorded in the companion JSON output. It is not a legal-accuracy claim and it does not use client documents.

## Scope and method

- Corpus: synthetic legal clauses generated by `backend/benchmarks/ocr_dataset.py`.
- Documents are rendered to PDFs, then selected pages are rasterised to image-only scans so extraction must use OCR.
- Ground truth is the exact page text and reading order expected from a perfect extractor. CER/WER are computed after Unicode, case and whitespace normalisation; punctuation and word order are preserved.
- `word order` is longest-common-subsequence recall over word tokens. It exposes reordered columns even when every word was recognised.
- Clause segmentation is measured against the original extracted text: exact source offsets, expected clause-marker recall and marker order.
- OCR confidence is line-level confidence weighted by line length. It is not word-level confidence and must not be read as a probability that a clause is legally correct.
- Peak memory is Python `tracemalloc` peak, not process RSS; native ONNX and OpenCV allocations are outside that measurement.
- Risk recall is measured against the expected rule codes hand-labelled for each synthetic case. False positives are recorded in the JSON.

## Evidence-based weaknesses and recommendations

- Highest character error rate: `stamped_page` at 0.0216 CER and 0.0161 WER. Inspect its page rows in the JSON result before changing thresholds.
- Lowest reading-order score: `skewed_page` at 0.9683. Inspect its page rows: both reordered text and character substitutions can reduce this score.
- Review flags were raised on: `blurry_page`, `table_page`. This is desirable only when the confidence actually correlates with the measured error.
- Recommendation: keep OCR confidence as a review signal, never as a legal-correctness score. Re-run this benchmark after changing preprocessing, layout ordering or merge thresholds.
- Recommendation: expand the corpus with real, consented, redacted scans before making production accuracy claims; this synthetic corpus is a regression harness, not a representative sample.
